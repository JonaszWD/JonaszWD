## Experience

**DMG Media (Daily Mail), Innovation Team**: Summer intern, June to July 2026, return offer received. Built a Whisper and ElevenLabs transcription pipeline with an LLM prompt chain that generates five headlines per podcast episode, added embeddings and a GPT-4o chatbot connected to the in-house RAG system, and made an interactive map narrowing ~120,000 UK businesses to ~50,000 barbershops for journalists.
